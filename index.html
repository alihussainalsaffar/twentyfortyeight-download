Tile Merge

Install Tile Merge

Flutter project by Ali Alsaffar: the twenty-forty-eight sliding tile game

Android

Swipe to slide the tiles, join equal numbers and reach 2048. Options let you pick the grid size, the starting tiles and the sound.

Download for Android (45 MB)
  1. Open the downloaded file.
  2. If asked, allow installing from this source.
  3. Tap Install, then Open.

iPhone

iPhone apps can't be installed from a web page, so this opens the same app in Safari.
